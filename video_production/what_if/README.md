# Shorts « Et si… ? » avec le skill What If

Skill MIT de FreshStack : https://github.com/kelano86/what-if-animation (épisodes de 15 à 25 s en bonshommes bâtons,
dessinés en code avec Remotion ; voix et bruitages ElevenLabs).

- `setup_studio.sh` : installe le studio et remplace les polices Google par des copies locales (le navigateur de
  l'environnement cloud ne peut pas charger Google Fonts).
- Il faut une clé `ELEVENLABS_API_KEY` pour créer ses propres épisodes. Offre gratuite ElevenLabs : non commerciale,
  avec mention d'ElevenLabs (selon le README du skill) ; forfait payant pour une chaîne monétisée.
- Règles du skill : personnages et histoires originaux, vérifier sur YouTube que l'idée n'existe pas, sourcer chaque fait.
- Les épisodes d'exemple (Pip, Mo, « Rewind », « CopyPaste ») appartiennent à l'auteur du skill : ne pas les publier.
