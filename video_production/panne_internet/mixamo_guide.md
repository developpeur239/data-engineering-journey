# Récupérer les personnages et animations Mixamo (environ 20 minutes)

Pourquoi c'est toi qui le fais : Mixamo demande de se connecter avec ton compte (Adobe ou Google).
Je ne peux pas me connecter à ta place et je ne dois jamais te demander ton mot de passe.
Une fois les fichiers sur ton Google Drive, je fais tout le reste (conversion, poses, mains sur les objets).

Mixamo est gratuit ; les personnages et animations sont utilisables sans redevance dans une vidéo YouTube.

## 1. Se connecter
1. Ouvre **https://www.mixamo.com** dans Chrome.
2. « Log in » → « Continuer avec Google » (ou crée un compte Adobe gratuit).

## 2. Les personnages (onglet « Characters »)
Tape le nom dans la recherche, clique sur le personnage, puis **DOWNLOAD** avec :
Format **FBX Binary (.fbx)** · Pose **T-pose** · cliquer DOWNLOAD.

| Rôle dans la vidéo | Nom à chercher | Si introuvable |
|---|---|---|
| Marc (34 ans, décontracté) | **Remy** | n'importe quel jeune homme en veste ou sweat |
| Voisin médecin (âgé) | **Malcolm** | un homme âgé |
| Pharmacien / commerçant | **Josh** | un homme adulte |
| Soignante / cliente | **Kate** | une femme adulte |
| Passants | **Brian**, **Jody** | 2 autres personnages variés |

(L'enfant de 2 ans n'existe pas sur Mixamo : je le garde en 3D fait maison, en l'améliorant.)

## 3. Les animations (onglet « Animations »)
1. Sélectionne d'abord **Remy** (en haut à droite, « Upload character » n'est pas nécessaire : choisis-le dans Characters).
2. Pour chaque animation : tape le mot, choisis la plus proche, puis **DOWNLOAD** avec
   Format **FBX Binary** · Skin **Without Skin** · Frames per second **30** · Keyframe Reduction **none**.

| Usage | Mot à chercher |
|---|---|
| Debout, respiration | Idle |
| Marcher | Walking |
| Courir | Running |
| Descendre un escalier | Descending Stairs |
| Monter un escalier | Ascending Stairs |
| Taper au clavier | Typing |
| Écrire à la main | Writing |
| Téléphoner | Talking On Phone |
| Regarder son téléphone | Texting |
| Porter un enfant / un carton | Carrying / Holding Idle |
| Inquiet, regarde autour | Looking Around |
| Dire non de la tête | Shaking Head No |
| Soulagé | Relieved Sigh |
| Assis | Sitting Idle |
| Payer / tendre la main | Reaching Out |

## 4. Me les envoyer
1. Mets tous les fichiers .fbx dans un dossier **Google Drive** (ex. « mixamo_panne »).
2. Clic droit sur le dossier → Partager → « Tous les utilisateurs disposant du lien ».
3. Envoie-moi le lien du dossier.
